# Generative AI — Learning Notes

A personal collection of notes, guides, and project ideas I'm using to learn Generative AI — covering core concepts, evaluation techniques, and hands-on project inspiration.

## 📖 About

This repo is my running knowledge base as I study Generative AI. It's not a polished course or a production codebase — think of it as a notebook: PDFs I've written or curated to understand key concepts, track project ideas, and revisit important techniques like RAG evaluation.

## 📂 Contents

| File | Description |
|---|---|
| `Generative AI Introduction to the Fundamentals.pdf` | Beginner-friendly primer covering the core concepts of Generative AI — what it is, how it works, and the foundational ideas behind modern generative models. |
| `Generative AI.pdf` | Broader notes on Generative AI, expanding on fundamentals with deeper explanations and concepts. |
| `20 GenAI Projects.pdf` | A curated list of 20 hands-on Generative AI project ideas, useful for practicing and applying concepts learned. |
| `RAG EVALUATIONS SIMPLE GUIDE.pdf` | A simple, practical guide to evaluating Retrieval-Augmented Generation (RAG) pipelines. |

## 🎯 Purpose

- Consolidate my learning as I go through Generative AI concepts
- Keep a reference guide for RAG evaluation techniques
- Maintain a backlog of project ideas to build and practice with
- Track progress and revisit notes as understanding deepens

## 🚀 How to Use

Browse the PDFs directly in this repo. They're organized roughly from **fundamentals → deeper concepts → applied projects → evaluation techniques**, so reading in that order works well if you're new here too.
